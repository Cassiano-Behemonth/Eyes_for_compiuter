🎨 Como Inserir Novos Temas

1. Crie uma pasta dentro de Temas/

O nome da pasta será o nome da criatura exibido aqui na lista (ex: Temas/Monstro_Cosmico).

2. Crie o arquivo tema.json dentro da pasta

Configure as cores que você deseja para a íris, fibras, escamas e veias:

{ "base": "Dragão", "iris": ["#ffffff", "#00ffff", "#0088ff", "#000044"], "fibras": ["#b0ffff", "#00aaff", "#001144"], "esclera": ["#001122", "#000511"], "veias": "#00ffff", "escamas": "#002244", "brilho": "#00ccff", "destaque": "#00eeff" }

3. (Opcional) Adicione texturas em PNG

Se quiser usar artes próprias desenhadas:

• iris.png: textura quadrada para a íris.

• esclera.png: fundo do olho.

• pele.png: fundo da tela inteira no lugar das escamas.

4. Recarregue no Protetor de Tela

Ao mexer o mouse, sua nova criatura já estará disponível imediatamente no menu!
